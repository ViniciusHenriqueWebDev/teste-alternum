# Calculadora Fullstack

Este projeto é uma aplicação fullstack simples onde o frontend envia um número para o backend, que multiplica por 10 e retorna o resultado.

## Estrutura do Projeto

O projeto está organizado nas seguintes pastas:

- `frontend/`: Contém o código do frontend em React
    - `src/`: Arquivos fonte do React
    - `public/`: Arquivos estáticos
- `backend/`: Contém o código do backend em Node.js

## Como Executar

1. Backend:
     ```bash
     cd backend
     npm install
     node server.js
     ```

2. Frontend:
     ```bash
     cd frontend
     npm install
     npm run dev
     ```

O frontend estará disponível em `http://localhost:5173` e o backend em `http://localhost:3000`.
